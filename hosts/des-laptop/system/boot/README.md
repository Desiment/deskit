# des-laptop Boot Sources

Reserved for reviewed, machine-specific rEFInd/EFI-stub configuration and
dual-boot sources. No deployable boot files are present yet; the current
kernel guide is under `../kernel/`, and the planning checklist is at
`../../../../docs/boot/`.

Never apply this directory automatically. Verify actual partitions and UUIDs
on the machine before adding boot entries or copying anything to the ESP.
